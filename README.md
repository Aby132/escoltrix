# Escoltrix Lightning Protection Solutions Website

## Project Description
This is the official website for Escoltrix Lightning Protection Solutions, a company specializing in advanced lightning protection, grounding systems, and surge protection devices. The website showcases their product range, services, and company information.

## Key Features
- **Modern Responsive Design**: Built with a "High-Tech/Glassmorphism" aesthetic using CSS3 and Flexbox/Grid.
- **Dynamic Product Catalog**: PHP-based product listing with filtering by category (Grounding Systems, Lightning Protection, Surge Protection, Exothermic Welding).
- **Product Details**: Dedicated informational pages for each product with specifications, features, and benefits.
- **Brochure Downloads**: Functionality for users to download product brochures (PDFs) directly.
- **Contact Forms**: Integrated contact for requesting quotes and general inquiries.
- **Animations**: Uses AOS (Animate On Scroll) for engaging visual effects.

## Technologies Used
- **Frontend**: HTML5, CSS3 (Custom & Responsive), JavaScript (Vanilla)
- **Backend**: PHP (Native)
- **Icons**: Font Awesome
- **Fonts**: Google Fonts (Inter)
- **Library**: AOS (Animate On Scroll)

## Project Structure
- `index.php`: Main landing page with Hero, News, Products preview, and Armour Rings section.
- `products.php`: Full product catalog with category filtering.
- `product-detail.php`: Dynamic single product view.
- `includes/`: Reusable components like `header.php` and `footer.php`.
- `assets/css/`: Stylesheets (`style.css`, `responsive.css`).
- `Images/`: Product images and assets.
- `pdf/`: Product brochures.

## Setup & specific instructions
1.  **Environment**: This project requires a PHP server environment (e.g., XAMPP, WAMP, or Apache with PHP).
2.  **Installation**:
    *   Place the project folder in your server's root directory (e.g., `htdocs` in XAMPP).
    *   Start the Apache module.
3.  **Access**: Open your browser and navigate to `http://localhost/cult1/` (or your specific folder name).
